# yuki0731/biohub-coord-inject (PUBLIC dataset, CC0-1.0, 25 Aug 09:41 UTC, 95 MB, 102 downloads; owner yuki0731 = team "LMM開発室のシルバーウィーク" with konbu17, public LB 0.961 #56, 142 subs) - text files pulled 26 Sep 21:00 UTC; the 8 .pt weights (4 detector seeds 12.7 MB each, z refiner 32 MB, xy refiners 6.6 MB) stay on Kaggle, re-download with `kaggle datasets download -d yuki0731/biohub-coord-inject --unzip`
1. Post-hoc NODE-POSITION injection: a 4-checkpoint "Dense2" detector (UNet3D base 24 + 3-channel offset head, input pooled 4x in xy, 4 flip views each) gives sub-voxel peaks per frame; a z refiner (R_ens4off_tr171_z, views 0/3) and an xy refiner (RprojQdistill_rot180_ens4off_tr171_xy, rots 0/180) move them; then every predicted node (read from the pipeline's .geff) is moved to the nearest refined detection if it lies within max_um 3.0 um (alpha 1.0). Node set, ids and edges are unchanged.
2. Manifest: "Runtime coordinate injection for rock0926 public notebook" (= rockerritesh/0-926-biohub-divsub, 23 Aug, a 0.926-era public notebook); local_eval_score 0.8397 for variant g3a1_xydist180e1r180 (no baseline number given, so no measured gain); "tr171" = refiners trained on 171 train videos (28 held out, which ones is not stated -> partly in-sample on our exp60 lab).
3. Differs from x138: x138 places nodes with its own decoder + linefit (K2 adds lowrefine); coord-inject is an independent learned localiser that could replace placements. Corwin's own note (k10_subvox.py) says placement is worth ~+0.006 public between two detectors, so placement is a live lever.
4. Plug-in path: apply `inject_one`'s rule to K2's submission.csv nodes per (dataset, t) (KD-tree in um, <= 3 um), or port the geff version; cost = 4 detectors x 4 views + 2 refiners per frame on 2xT4 (not timed by us), so it must fit under the 7.5 h ledger.
5. Verdict: the only public, CC0, plug-compatible model artifact in the 0.960-0.966 band; UNPROVEN on x138 (no LB number anywhere). Needs a lab A/B on exp60 (in-sample caveat) + 1 public probe. Source: https://www.kaggle.com/datasets/yuki0731/biohub-coord-inject
