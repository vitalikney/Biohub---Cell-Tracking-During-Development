# New to Biohub? Fork this CPU cell-tracking baseline + validation toolkit

https://www.kaggle.com/competitions/biohub-cell-tracking-during-development/discussion/742794  
author Yang Kuang Ou, posted 2026-09-23 13:53:04.969000, votes -2, comments 0, last comment None

<p>Want a clean place to start building a Biohub cell tracker? This public Notebook is a forkable CPU starter kit: a small baseline plus checks and visualizations to help you understand what your pipeline is doing.</p>
<p><strong>What you can try</strong></p>
<ul>
<li>CPU baseline: intensity thresholding → connected components and centroids → greedy nearest-neighbor links.</li>
<li>Embryo-grouped validation helpers for leakage-aware comparisons.</li>
<li><code>.geff</code> graph inspection, physical-coordinate visualizations, and sparse-label-aware edge diagnostics.</li>
</ul>
<p><strong>Get started:</strong> open the <a href="https://www.kaggle.com/code/yangkuangou/biohub-public-simple-baseline-validation" target="_blank">Notebook</a>, fork it privately, attach the competition input, and enable <code>RUN_BASELINE_ON_TEST</code> to create a candidate CSV. It does not submit anything.</p>
<p>It is intentionally a simple learning baseline, with no trained detector or division handling. The public run reports no validation or leaderboard score, so treat it as a starting point to extend, not a performance claim. No private model, weights, or post-processing are included. Licensed under Apache 2.0.</p>
<p>What would you add first: motion cues, division handling, or a stronger detector? Feel free to fork and build on it.</p>
