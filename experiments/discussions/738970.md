<p>Regarding image or language-based tasks: Currently, the publicly available code relies on fairly well-defined metrics; everyone is using the same base files but fine-tuning the parameters. Personally, I think that if you want to win a medal, you should try creating new variable axes (such as lighting, angles, intensity, etc.). If you simply compete by tuning the existing baseline, winning a medal will be difficult, as people are likely tuning and sharing their configurations—effectively allowing everyone to copy the best approaches—given the current trends in this competition.</p>
