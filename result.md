# Результаты Friend A: leak-free LOEO detector from scratch

Дата запуска: 6 сентября 2026 года.

Статус: обучение завершено, лучший checkpoint сохранён и оценён официальной метрикой на независимых 12 видео `44b6`, до и после фиксированного post-processing v2.

## Постановка эксперимента

- Обучение с нуля, без `--init-weights`, `--unet-weights` и сторонних checkpoint.
- Train: фиксированные 126 видео эмбриона `6bba` из `experiments/_lib/loeo_train6bba_val44b6.json`.
- Validation: 12 фиксированных видео эмбриона `44b6`, не использованных для обучения.
- Таким образом, граница LOEO между эмбрионами соблюдена.
- Эпох: 5.
- Seed: 42.
- Batch size: 4.
- Learning rate: `1e-4`.
- Temporal window: 2 кадра.
- Downsample `(Z, Y, X)`: `(1, 4, 4)`.
- Loss: BCE для детектора.
- AMP: включён.
- DataLoader workers: 0 — устойчивый режим для Windows.

## Официальная LOEO-оценка

Для лучшего checkpoint выполнен полный инференс с порогом детектора `0.965`, TTA, NMS `5 мкм` из сохранённой конфигурации и ILP-параметрами `appearance=0`, `disappearance=2`, `division=1.2`. Затем применён ранее зафиксированный post-processing v2: gap closing `5 мкм`, direct linking `8 мкм`, post-hoc divisions `5/12 мкм`. Все 12 видео из фиксированного `LOEO-44b6` holdout успешно обработаны. Результат повторно проверен закреплённым evaluator организаторов из `vendor/kaggle-cell-tracking-competition`; пропущенных видео нет.

| Метрика | Значение |
|---|---:|
| Официальный score, сырой граф | 0.670620 |
| Официальный score, post-processing v2 | **0.689091** |
| Adjusted edge Jaccard после post-processing | 0.686917 |
| Raw edge Jaccard после post-processing | 0.685598 |
| Division Jaccard после post-processing | 0.021739 |
| Division TP / FP / FN после post-processing | 1 / 31 / 14 |
| Node recall после post-processing | 0.864856 |
| Edge TP / FP / FN после post-processing | 3380 / 567 / 983 |
| Предсказанных узлов после post-processing | 519106 |
| Оценённых видео | 12 / 12 |

Итог рассчитан по формуле соревнования `adjusted_edge_jaccard + 0.1 * division_jaccard`. Сырой ILP-граф не содержал верно найденных делений (`0/0/15`); post-processing восстановил одно, но добавил 31 ложное. Это честная локальная LOEO-оценка на другом эмбрионе, но не результат public/private leaderboard.

Контрольный инференс, буквально повторяющий внутренний validator (`logit > 0.3`, NMS `5 мкм`, без TTA), дал `0.660322`. Поэтому низкий итог не вызван evaluator или единственным неудачным порогом: после пяти scratch-эпох главным ограничением остаётся качество linker/division-части. Predictor исправлен так, чтобы NMS по умолчанию читался из `config.json`; ранее он молча использовал `3 мкм`. При пороге `0.965` старый и исправленный NMS случайно дали одинаковый граф и одинаковый raw score.

## Результаты по эпохам

| Эпоха | Edge loss | Detector loss | Validation loss | Accuracy | Recall | Внутренний `accuracy * recall` |
|---:|---:|---:|---:|---:|---:|---:|
| 1 | 0.0040 | 0.0193 | 0.0003 | 0.9996 | 0.8628 | 0.8625 |
| 2 | 0.0006 | 0.0140 | 0.0002 | 0.9998 | 0.8766 | 0.8764 |
| 3 | 0.0005 | 0.0126 | 0.0002 | 0.9998 | 0.8783 | 0.8781 |
| 4 | 0.0005 | 0.0120 | 0.0002 | 0.9998 | **0.8944** | **0.8943** |
| 5 | 0.0005 | 0.0110 | 0.0002 | 0.9998 | 0.8830 | 0.8828 |

Лучший результат validation получен на эпохе 4. На эпохе 5 training loss продолжил уменьшаться, но recall снизился с 0.8944 до 0.8830. По этому запуску нет признаков, что модель явно недообучена; продолжение до 8–10 эпох стоит проверять только отдельным экспериментом и выбирать по независимой официальной метрике.

`Accuracy`, `recall` и их произведение выше — внутренняя sparse-GT диагностика обучающего скрипта. Это не официальный score соревнования и не оценка полного false-positive rate, поскольку GT разрежен.

## Вывод и что осталось

Checkpoint эпохи 4 получил raw LOEO score `0.670620` и `0.689091` после post-processing v2. Детектор находит значительную часть размеченных центров, но полную графовую метрику ограничивают пропущенные и неверные связи и почти отсутствующее распознавание делений. Следующий полезный шаг — дополнительное scratch-обучение и улучшение linker/division-части с тем же неизменным `LOEO-44b6` протоколом. Оценка смешанного 48-видео набора для этой модели не является полностью независимой, поскольку его `6bba`-часть пересекается с обучающим эмбрионом. Отправка на leaderboard не выполнялась.
