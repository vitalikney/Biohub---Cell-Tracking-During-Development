## 3. Жёсткие правила
- Каждый сабмит — только после явного OK пользователя в чате (ночной — заранее, с условиями). Никогда не сабмить
  побайтную копию x138 как финал и не отмечать два почти одинаковых файла.
- Ядра собирать только через `tools/build_probe_kernel.py`. Каждая новая стадия: побайтно тот же CSV, когда выключена;
  fail-soft с громкой строкой `<STAGE> FAILED`; счётчики в логе.
- Git: ветка `claude/practical-meitner-31k9ye`, перед пушем `git pull --rebase`, без force-push. В `CONTEXT.md` только
  дописывать записи с датой и временем UTC. Коммиты от имени пользователя, без строк `Co-Authored-By` (так попросил
  пользователь). Файлы больше 20 МБ в git не класть.
- Не делать (R9): переобучение детектора/рёбер/головы к 29.09, зонд размера скрытого теста (N2), консенсус по тестовым
  кропам, axis-flip на x138, лестницы ручек на public.
