## 1. Опрос сабмитов (с 14:30 UTC 25.09, дальше постоянно до 29.09)

Задержка сабмит → счёт — наш главный бесплатный измеритель времени на скрытом тесте. CLI показывает только время
сабмита, поэтому время появления счёта фиксируем сами. Создай `experiments/lb_poll/lb_poll.py`:

```python
import datetime, pathlib, subprocess, time
LOG = pathlib.Path("experiments/lb_poll/poll.log")
LOG.parent.mkdir(parents=True, exist_ok=True)
CMD = ["kaggle", "competitions", "submissions", "biohub-cell-tracking-during-development", "-v"]
while True:
    ts = datetime.datetime.now(datetime.timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ")
    try:
        out = subprocess.run(CMD, capture_output=True, text=True, timeout=180).stdout
    except Exception as exc:  # сеть, CLI
        out = f"ERROR {exc}"
    with LOG.open("a", encoding="utf-8") as f:
        f.write(f"=== {ts}\n" + "\n".join(out.strip().splitlines()[:10]) + "\n")
    time.sleep(600)
```

Запусти его в фоне (`python experiments/lb_poll/lb_poll.py`). Если CLI старый, вместо позиционного имени
используй `-c biohub-cell-tracking-during-development`. Лог коммить при каждом событии (появился счёт или ошибка) и
раз в несколько часов. **Первое появление** счёта или ошибки у каждого сабмита записывай в CONTEXT одной строкой:
`#34 exp56: 0.953, first seen 15:31Z, L34 ≤ 7.37 h`. Если статус «error», открой страницу Submissions в Chrome и
перепиши точный текст ошибки: таймаут, исключение, «CSV not found» — это разные сигналы.

Сабмиты на 25.09 (`browser_intel.md` §6.0A): #34 = exp56 (id 56545267, 08:09:00 UTC), #35 = exp57b (id 56545786,
08:33:25 UTC).
