# Промпт для сессии на компьютере пользователя (Claude Desktop + Chrome) — разведка Kaggle для workflow v3

Скопировать целиком в новую сессию Claude, запущенную в локальном клоне репозитория.

---

Ты помогаешь команде Kaggle «Biohub - Cell Tracking During Development» (команда: vitaliineibauer, Sasyami, gsfatakhov).
Цель — 0.99 к 29 сентября. В облачной сессии сейчас работают исследовательские агенты (ideas workflow v3). Им закрыт
доступ к kaggle.com, arXiv и форумам. Твоя задача — стать их глазами на Kaggle: собрать свежие факты через браузер
Chrome (и Kaggle CLI, если он настроен на этом компьютере), записать их в репозиторий и запушить. Итоговая сводка
агентов начнётся примерно в 12:30 UTC 25 сентября. Всё, что ты запушишь до этого времени, в неё попадёт, поэтому
пушь частями, как только что-то готово.

## Подготовка (5 минут)
1. В локальном клоне выполни `git status`. Если есть незакоммиченные изменения, НЕ трогай их: сделай отдельный worktree
   (`git worktree add ../biohub-browser claude/practical-meitner-31k9ye`) и работай там. Если дерево чистое:
   `git fetch origin claude/practical-meitner-31k9ye && git checkout claude/practical-meitner-31k9ye && git pull`.
2. Прочитай `research/wf_ideas_v3/BRIEF.md`: там состояние проекта, метрика, наша база (x138, 0.950–0.953) и политика.
3. Файл результата: `research/wf_ideas_v3/browser_intel.md`, на английском, как остальные логи агентов. Каждый факт
   снабжай ссылкой (URL) и датой, догадки помечай как догадки.
4. Пушь в ветку `claude/practical-meitner-31k9ye`. Перед каждым пушем делай `git pull --rebase`: облачная сессия
   пушит туда же. Меняй только `research/wf_ideas_v3/browser_intel.md` и новые папки `experiments/ext_<slug>/`.

## Правила
- Только чтение публичной информации. НЕ отправлять сабмиты, НЕ пушить ноутбуки на Kaggle, НЕ писать в обсуждения,
  НЕ голосовать, НЕ скачивать данные соревнования (82 ГБ).
- Не использовать публичные треки или записи как ответы для скрытого теста (политика команды). Если найдёшь, что кто-то
  так делает, просто запиши это как факт.
- Chrome: работай в новых вкладках, личные вкладки пользователя не трогай, свои вкладки в конце закрой.

## Что собрать (по порядку; после пунктов 1 и 2 сразу закоммить и запушь)
1. **Лидерборд** (https://www.kaggle.com/competitions/biohub-cell-tracking-during-development/leaderboard): топ-50
   (место, команда, счёт, число сабмитов, дата последнего сабмита). Сколько команд набрали >= 0.953, >= 0.960 и
   >= 0.970. Место нашей команды (vitaliineibauer). Что изменилось по сравнению с 24 сентября: тогда топ был
   0.969–0.975, а на 0.953 стояла 41 команда.
2. **Публичные ноутбуки** (вкладка Code, сортировка по лучшему счёту; если настроен CLI:
   `kaggle kernels list --competition biohub-cell-tracking-during-development --sort-by scoreDescending --page-size 100`).
   Нужны все ноутбуки со счётом >= 0.950 и все, созданные или обновлённые после 22 сентября. Для каждого запиши:
   автор, название, счёт, версия, дата, чем он отличается от `anvithpothula/biohub-x138` (судя по markdown и первым
   ячейкам), какие датасеты и веса подключает, время выполнения. Код каждого ноутбука выше 0.953 или с новой идеей скачай:
   `kaggle kernels pull <owner>/<slug> -p experiments/ext_<slug>`. Если CLI не настроен, сохрани главное вручную в
   `experiments/ext_<slug>/NOTES.md`. Для каждой такой папки добавь пять строк: что нового по сравнению с x138.
3. **Обсуждения** (вкладка Discussion, сортировки Recent и Hot): все темы за последние 10 дней, а также любые темы про
   0.96–0.97+, переобучение детектора, точность координат (V1284 / coordinate head), деления, число узлов и N_est,
   состав теста (сколько эмбрионов и видео), ожидаемую перетряску на приватной части, лимит времени выполнения,
   внешние данные (Zebrahub / Ultrack). Для каждой темы: ссылка, автор (и его место на лидерборде, если видно), дата,
   суть в 2–4 строках, ключевые цитаты дословно.
4. **Датасеты**, связанные с соревнованием (новые веса, псевдоразметка, внешние данные): владелец, название, дата,
   содержимое.
5. **Страницы Overview / Data / Rules**: правила про внешние данные и предобученные модели, описание теста, порядок
   выбора финальных сабмитов, лимиты. Только то, что относится к делу, с дословными цитатами.
6. **Запросы агентов.** Каждые ~20 минут делай `git pull` и проверяй поле `browser_todo` в
   `research/wf_ideas_v3/h_*.json`, а также файл `research/wf_ideas_v3/BROWSER_TODO.md`, если он появился (туда
   облачная сессия сведёт все запросы). Выполни эти запросы и допиши ответы в раздел «Agent requests» файла
   `browser_intel.md`, указывая, чей это запрос.

## Формат `browser_intel.md`
```
# Browser intel (Kaggle), <дата/время UTC>
## 1. Leaderboard snapshot
## 2. Public notebooks >= 0.950 or updated after 22 Sep (table + per-notebook notes; pulled code paths)
## 3. Discussions (newest first)
## 4. Datasets
## 5. Rules / data / overview facts
## 6. Agent requests (browser_todo) and answers
## 7. Top 5 takeaways for reaching 0.97+ (your own reading, marked as opinion)
```

## Когда закончить
Примерно через 60–90 минут или когда пункты 1–6 закрыты. Сделай финальный коммит и пуш с сообщением
`Browser intel: Kaggle leaderboard, notebooks, discussions (<время UTC>)` и напиши пользователю 5 строк: что главное
нашлось и какие файлы изменены.
