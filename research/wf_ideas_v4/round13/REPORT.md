## 5. Отвергнуто

- **PC13-01 (a)/(b).** MEMORY уже обновлена в 22:46:44Z, LESSONS — к 30.09. Осталось только чтение SELECTED.
- **PC13-06 — «V* с L_hi > 8.0 ч не допускается».** Гейт работает по клипу, в L входят очередь и интервал опроса, строка V4-5 этот риск уже оценила. Правило заменило бы лучший V* на #37, то есть EV < 0.
- **То же правило «безусловно» (исправление скептика R13L-3).** Причина та же.
- **G2 как блок публичной пробы exp72 (R13-RC-A a).** Проба стоит слот, а не очки. Вето G2 нужно в строке финала.
- **Исходный дамми-гейт PC13-05.** ±3% узлов не проверяют качество, а «+15% runtime» ломается на шуме.
- **R13NC-3 как «точный K2» с P(0.955) 0.10–0.25.** На стенде нет lowrefine, P36 уже содержал lp30. Реалистично 0.05–0.15.
- **R13NC-5 (обрезка стартовых листьев).** Прирост на 44b6 — чистая арифметика узлов, p рёбер in-sample, неверный порядок хука, класс закрыт, нужен новый код после R8.
- **R13NC-6 (компоненты с низким средним p).** На деле это выброс readmit/relink: у всех выбранных компонент есть рёбра с p = 0. Плюс in-sample, обрыв близко, эффект ниже шага показа.
- **R13DP-3 (divergence 2.5/2.75, exp70n/o/j/m).** Приор GT 4/35, всего 4 FP на одном эмбрионе, значение подобрано по сетке, класс C.
- **R13DP-4 tau как ступень.** Знак зависит от эмбриона.
- **R13DP-2 «снимает риск L2» и «лучшая ручка для комбо».** 44b6 — обучающие клипы DeepCenter.
- **R13-RC-B «возрождён / ни одна ручка не отрицательна / аддитивно».** Стенд in-sample, у правок непересекающиеся носители, для решений ценность 0.
- **R13-RC-C (условное вето по 6bba).** Канал вреда не воспроизводится со вставкой; вето срабатывало бы редко; #38 уже страхует; стоит ~6 GPU-ч; правило принималось бы после счёта.
- **GF-3 (гейт по полосе детекции).** Неверный охват (сюда же пулы lowdet, readmit, gapfill и lowrefine), по сути откат к primary (I-102 −0.002 на LB), честного лаба нет.
- **GF-4 (max-union guard).** Во всех 715 fallback-кадрах blend ≤ primary, то есть это текущий fallback плюс дубликаты. Рычаг добавления узлов из семейства I-222.
- **Формулировка GF-5 «потолок +0.0011 → ≤ +0.0002 public».** +0.0011 — только актуальная часть; правило 1/6 к оракулу не применяется. Закрытие остаётся.
- **Имена C5–C9 в R13L-5.** Конфликт с C5 из v2, приоры не сходятся с правилом 1/6. Заменены на L1–L5.
- **Ранний дамми комбо в D1.** Был бы впустую с вероятностью ~95%. Дамми пушится только после POS-чтения fm45.
- **Условие PC13-03 «тот же Score и SubmissionCount» для обогнанной команды.** Не нужно: публичные лучшие результаты не убывают, а условие только снижает мощность теста.
