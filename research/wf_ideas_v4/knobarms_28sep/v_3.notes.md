- tracksdata 0.1.0rc9 _ilp_solver.py flow identities (no merges): #appear = #nodes - #edges and #disappear = #appear + #div.
  => objective = (A+Dis)*#appear + (Dis+Div)*#div - sum p*e. The solution depends only on S = A+Dis (the fragment/track-start price) and on the fork threshold T-S = Div - A.
  - Current setting: S=2, fork threshold 1.2. No fork is possible because p <= 1.
  - A=-0.2 gives S=1.8, fork threshold 1.4, so still no forks. This is the SAME ILP solution as DISAPPEARANCE 1.8 (the #div term is 0 in both).
  - A=0.4 gives S=2.4, fork threshold 0.8. This is the SAME ILP solution as DISAPPEARANCE 2.4 + DIVISION 0.8.
- Toy ILP check (v_3_equiv.py; ilpy with SCIP, 3 random graphs of 8x12 nodes):
  - A=-0.2 vs Dis 1.8: identical node counts. Where the solutions differ (seed 1), the objectives are equal (-14.737063992 both), so these are tied optima.
  - A=0.4 vs Dis 2.4 + Div 0.8: identical node counts. 2 of 3 solutions are identical, and the third has equal counts.
- Verdict: REFUTED as a use of a slot. The knob is not an independent axis.
  - The down arm is an exact duplicate of a D-down arm.
  - The up arm is the diagonal of the D-up arm and a milder exp85a (division 0.8 < 1.2, fork opening at p2 > 0.8 vs 85a's 0.4). exp85a (probe 50) is pending and the D pair is proposed in arms_0, so this pair only confounds the two pure axes.
  - Fork half: it has no direct output channel (relink replaces ILP edges), same as 85a.
